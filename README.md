# 🏠 سكني في وارسو — منظّم البحث عن أوضة أو ستوديو أو شقة

موقع خاص (بباسورد) على Cloudflare Workers بيساعدك تقارن اختيارات السكن في وارسو، سواء أوضة أو ستوديو أو شقة:
كل مكان ليه كارت فيه السعر والمصاريف واللينك وجهة التواصل، وعلامات ✓ / ✗ / ؟ لكل فلتر من فلاترك،
والموقع بيرتّب الاختيارات تلقائيًا من الأحسن للأوحش حسب سكور ذكي.

## المميزات

- 🔐 **باسورد**: الموقع مقفول بباسورد (`777` افتراضيًا) — تقدر تشيّر اللينك مع صاحبك.
- 🌍 **عربي / إنجليزي**: زرار عائم بيبدّل اللغة والاتجاه (RTL/LTR) — الافتراضي إنجليزي، وعناوين وملاحظات الإعلانات نفسها متخزنة باللغتين.
- 🌓 **دارك / لايت مود**: زرار عائم تاني بيبدّل الثيم — الافتراضي لايت كريمي مريح للعين، والاختيارات بتتحفظ في المتصفح.
- ⚡ **حط اللينك بس**: في إضافة أوضة، الصق لينك OLX أو Otodom واضغط Auto-fill؛ الموقع يجيب الاسم والسعر والمرافق والديبوزيت والعنوان والتواصل والصور، ويستنتج الفلاتر الواضحة من النص. الحاجات البصرية غير المؤكدة تفضل `؟` لحد ما تراجع الصور بدل التخمين.
- 🖼️ **معرض صور كامل**: كروت في عمودين، تقليب يمين/شمال، عداد صور، وتكبير بملء الشاشة مع زووم.
- 💵 **تقسيمة سعر واضحة**: الإيجار، المرافق وكل حاجة غير الإيجار، الجراج لو فيه (دايمًا بيتحسب إضافي)، والإجمالي من غير الجراج + الديبوزيت.
- ✅ **علامات لكل فلتر**: فرن، سرير مريح، أوضة واسعة، جراج، ٣ أوض أو أقل، مكتب كبير، شقة مودرن، أسانسير، متاحة من ١ أغسطس، من غير كوميشن. دوس على أي علامة تقلبها (أيوه ← لأ ← مش متأكد) وبتتحفظ لوحدها.
- 🏆 **ترتيب تلقائي بالسكور**: كل معيار ليه وزن، والسعر وقرب الشغل (Lionbridge — Łopuszańska 95) داخلين في الحساب. أحسن ٣ بياخدوا ميداليات.
- 🚌 **لينك مواصلات جاهز**: زرار بيفتح جوجل مابس بالطريق من العنوان للشغل.
- ✏️ **تعديل وإضافة**: ضيف أوض جديدة، عدّل الأسعار والملاحظات، أو امسح اللي اتأجرت.
- 📱 شغال على الموبايل، والبيانات متخزنة في Durable Object (مش في المتصفح) فبتفضل متزامنة بينك وبين صاحبك.

## التشغيل محليًا

```bash
npm install
npm run dev        # http://localhost:8787 — الباسورد 777
```

## النشر على حسابك في Cloudflare

```bash
npx wrangler login   # سجّل دخول بحسابك (مجاني)
npm run deploy       # هيطلعلك لينك https://warsaw-rooms.<حسابك>.workers.dev
```

مفيش أي إعدادات إضافية — الـ Durable Object بيتعمل تلقائيًا مع أول deploy.

## تغيير الباسورد

- غيّر `SITE_PASSWORD` في `wrangler.jsonc`، أو
- اعمله سيكرت بعيد عن الكود: `npx wrangler secret put SITE_PASSWORD` (بياخد الأولوية على القيمة اللي في الملف بعد ما تشيلها من `vars`).

## تعديل أوزان السكور

الأوزان موجودة في أول ملف `public/app.js` في مصفوفة `CRITERIA` — زوّد وزن الحاجات اللي تهمك أكتر.

## هيكل المشروع

```
├── wrangler.jsonc      # إعدادات الـ Worker
├── src/
│   ├── index.ts        # السيرفر: بوابة الباسورد + API

    ├── index.html      # الواجهة
    ├── style.css       # التصميم
    └── app.js          # المنطق: السكور والترتيب والفلاتر
```
